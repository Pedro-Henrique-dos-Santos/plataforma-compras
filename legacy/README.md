# Sistema legado

Esta pasta preserva a versao funcional em Google Apps Script antes da migracao para React e NestJS.

- `apps-script/`: backend e interfaces implantados na planilha.
- `tests/`: validacoes existentes do portal.
- `docs/`: instrucoes e registros de implantacao.
- `samples/`: documentos ficticios usados em testes de leitura.

O conteudo nao deve ser implantado automaticamente nem removido durante a construcao da nova plataforma.
